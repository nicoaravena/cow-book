# 1.2 Opening hours

Step 1.2 adds `cowbook/hours.go`: `ClockTime`, `OpeningWindow`, `WeeklyHours` and
`WeeklyHours.Contains`, which tells whether a period fits inside one opening window. `NewSpace` now
requires opening hours.

## Instants vs wall clock

A `time.Time` is an **instant**: one point in time, the same everywhere, plus a location used only
for display. "Open 09:00 to 17:00 on Mondays" is not an instant, it's what a **wall clock** shows
in some place. The two meet only through a timezone:

```go
localStart := start.In(loc)
```

`In` keeps the instant and changes the location, so `Clock()`, `Weekday()` and `Date()` read the
local wall clock. Bookings are stored as instants; opening hours are compared in the space's
location's timezone. Which location the inputs happen to carry doesn't matter, and a test proves it.

## Value types

```go
// ClockTime is a time of day as read on a wall clock, to the minute. It has
// no date or timezone. 24:00 is valid and means the very end of the day.
type ClockTime struct {
	minutes int
}
```

`ClockTime` is a small struct passed by value, like `time.Time` itself. It has no identity: two
`ClockTime`s holding 540 minutes are the same 09:00. Its one field is unexported, so the only way to
get one is `NewClockTime`, which refuses 25:00 or 09:75. A plain `int` would accept those.

## Methods

```go
func (c ClockTime) sinceMidnight() time.Duration {
	return time.Duration(c.minutes) * time.Minute
}
```

A method is a function with a **receiver** written before its name. Any named type declared in the
package can have methods, not only structs. A value receiver, as here, works on a copy; 1.4 covers
pointer receivers.

## Arrays, slices and sorting

```go
type WeeklyHours struct {
	days [7][]OpeningWindow // indexed by time.Weekday, each day sorted by Open
}
```

- `[7]T` is an **array**: fixed length, part of the type, copied whole on assignment.
  `time.Weekday` is an integer from `Sunday` (0) to `Saturday` (6), so it indexes it directly.
- `[]T` is a **slice**: a view over a backing array, with a length and capacity. `append` grows it.
- The zero `WeeklyHours` is seven nil slices, which is "closed all week". No constructor needed for
  that case.

`NewWeeklyHours` sorts each day with the generic `slices.SortFunc` and `cmp.Compare` (Go 1.21),
then rejects windows that overlap or touch.

## Durations

`time.Duration` is an `int64` count of nanoseconds. Constants such as `time.Minute` are durations,
so `24 * time.Hour` reads naturally. Multiplying a plain `int` by one needs a conversion:
`time.Duration(c.minutes) * time.Minute`.

## Daylight saving time

Clocks jump, so a day is not always 24 hours, and some wall-clock times happen twice or never.
`Contains` handles the edges:

- It compares the start and the **last moment** of the period (`end - 1ns`) on the local clock.
  Ending exactly at midnight stays on the earlier day, even where the next day starts at 01:00.
- `sinceMidnight` uses what the clock shows (`t.Clock()`), not elapsed time since midnight, because
  opening hours are written as clock times.

Tests load real zones with `time.LoadLocation("America/New_York")` and `"America/Santiago"` and
check bookings right at each jump. One known gap, written up under Risks in the roadmap: only the
two ends are checked, so a window edge inside a repeated hour can be missed. A test pins that
behavior.

## Test helpers

```go
func loadLocation(t *testing.T, name string) *time.Location {
	t.Helper()
	loc, err := time.LoadLocation(name)
	if err != nil {
		t.Fatalf("time.LoadLocation(%q) error = %v, the zone database may be missing", name, err)
	}
	return loc
}
```

`t.Helper()` makes a failure report the line of the caller, not this line inside the helper.
