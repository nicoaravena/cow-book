# 1.1 Space

Step 1.1 moves `Space` into `cowbook/space.go` and gives it a constructor, `NewSpace`, that refuses
a space breaking any rule. From here on the only way to get a valid `Space` is through it.

## Exported and unexported names

A name starting with a capital letter is **exported**: other packages can use it. Lowercase names
are visible only inside the package. That is Go's only access control: there is no `private` or
`public` keyword, and it works per package, not per type.

```go
type Space struct {
	ID               int64
	locationID       int64
	name             string
	kind             SpaceKind
	capacity         int
	...
}
```

Code outside `cowbook` can't set `capacity` to `-3`, because it can't name the field at all. `ID`
stays exported because the store assigns it after saving.

## Constructors

Go has no constructors in the language. The convention is a function `NewX` that returns a ready
value:

```go
func NewSpace(p SpaceParams, now time.Time) (Space, error) {
	name := strings.TrimSpace(p.Name)

	switch {
	case p.LocationID <= 0:
		return Space{}, ErrInvalidLocation
	case name == "":
		return Space{}, ErrSpaceNameRequired
	...
	}

	return Space{locationID: p.LocationID, name: name, ..., available: true}, nil
}
```

- **A params struct.** Six positional arguments of similar types are easy to swap by mistake.
  `SpaceParams` has exported fields, so callers fill it by name.
- **`now` is passed in.** The function never calls `time.Now()` itself, so a test chooses the time.
  1.5 does the same for services with an injected clock.
- **First broken rule wins.** A `switch` with no value (`switch {`) runs the first `case` that is
  true. Callers get one error, always the same one for the same input.
- **The zero value on error.** `return Space{}, err` is the convention: when `err` is not nil, the
  other result means nothing and callers must not use it.

## Sentinel errors

```go
var (
	ErrInvalidLocation   = errors.New("space needs a valid location")
	ErrSpaceNameRequired = errors.New("space name is required")
	...
)
```

A **sentinel** is an error value created once, at package level, that callers compare against.
Errors in Go are ordinary values returned as the last result, not exceptions. The HTTP layer (M3)
will map each sentinel to a status code. Names start with `Err`, by convention.

## String enums

```go
type SpaceKind string

const (
	KindHotDesk       SpaceKind = "hot_desk"
	KindMeetingRoom   SpaceKind = "meeting_room"
	...
)

func (k SpaceKind) valid() bool { ... }
```

A named type over `string` documents intent and lets `SpaceKind` have methods. It doesn't stop
anyone writing `SpaceKind("sauna")`, so `NewSpace` still checks `valid()`. The string values are
what will end up in the database and the API.

## `int64` IDs

The first draft used `uint64` and `uint8`. Step 1.1 switched to `int64` IDs and `int` capacity:
Postgres `bigint` is signed, sqlc generates `int64`, and an unsigned count only turns a negative
input into a huge positive one instead of something the validation can see.

## Table-driven tests

```go
func TestNewSpaceValidation(t *testing.T) {
	tests := []struct {
		name    string
		change  func(p *SpaceParams)
		wantErr error
	}{
		{"valid params", func(p *SpaceParams) {}, nil},
		{"zero location", func(p *SpaceParams) { p.LocationID = 0 }, ErrInvalidLocation},
		...
	}
	for _, tt := range tests {
		t.Run(tt.name, func(t *testing.T) { ... })
	}
}
```

- Each case is one row: a name, the change, the expected result. Adding a rule adds a row.
- `validSpaceParams()` returns params that pass, and each row changes **one** field, so a failure
  points at exactly one rule.
- `t.Run` makes each row a **subtest**, reported by name and runnable alone:
  `go test -run 'TestNewSpaceValidation/zero_location' ./cowbook`.
