# 1.3 Booking rules

Step 1.3 adds `cowbook/booking.go` with `NewBooking`, which checks every README rule that doesn't
depend on other bookings: a stored and available space, at least one attendee and no more than the
capacity, end after start, not in the past, no longer than the limit, inside one opening window.

Overlaps are not checked here. Only something that sees every booking can do that: the store
(1.8 in memory, 2.3 and 2.5 in Postgres).

## The rules as one switch

```go
func NewBooking(space Space, loc *time.Location, p BookingParams, now time.Time) (Booking, error) {
	// Sub gives real elapsed time, so a clock change can't stretch or shrink it.
	length := p.End.Sub(p.Start)

	switch {
	case p.MemberID <= 0:
		return Booking{}, ErrInvalidMember
	case space.ID <= 0:
		return Booking{}, ErrInvalidSpace
	...
	case p.Attendees > space.capacity:
		return Booking{}, fmt.Errorf("%w: %d attendees, capacity %d", ErrOverCapacity, p.Attendees, space.capacity)
	...
	case !space.hours.Contains(p.Start, p.End, loc):
		return Booking{}, ErrOutsideOpeningHours
	}
	...
}
```

- `NewBooking` takes the whole `Space`, so it reads its unexported fields directly: both are in
  package `cowbook`.
- `loc` comes separately because a space doesn't know its timezone; its location does (1.5 has the
  store return both).
- Length uses `Sub`, which is real elapsed time. Across a DST jump, 09:00 to 13:00 on the wall clock
  can be 3 or 5 hours, and the limit is about how long the room is used.
- `!p.Start.Before(p.End)` reads as "start is not before end", which covers equal times too.

## Wrapping errors with `%w`

Some errors carry details: how many attendees, what the limit was. `fmt.Errorf` with the `%w` verb
builds a new error whose message includes the details and which **wraps** the sentinel:

```go
err := fmt.Errorf("%w: %d attendees, capacity %d", ErrOverCapacity, 9, 8)
// err.Error() == "booking exceeds the space's capacity: 9 attendees, capacity 8"
```

`%v` would copy the text only; `%w` also keeps a link to the original value.

## `errors.Is`

A wrapped error is a new value, so `err == ErrOverCapacity` is false. `errors.Is(err, target)`
follows the chain of wrapped errors and reports whether any of them is `target`:

```go
if errors.Is(err, cowbook.ErrOverCapacity) { ... } // true, wrapped or not
```

That's why every error comment in `cowbook` says "callers compare them with `errors.Is`", even for
errors returned bare today: a later step may add detail without breaking callers. A test checks both
sides: `errors.Is` matches, and `err == sentinel` does not, so the detail is really there.

## Cancelled as a timestamp

The first draft had `deletedAt` on `Booking`. 1.3 renames it `cancelledAt`: a cancelled booking is
kept, with its time, for history ("which member booked a room last Tuesday"). A zero `time.Time`
means "not cancelled"; `IsZero` tests it. 1.6 builds a whole state model on this.

## Attendees

The README asks for a capacity rule, so a booking needs to know how many people are coming.
`attendees` is new; the roadmap's domain model notes it.
